# App icons

SYNQ's icons are Liquid Glass documents from Icon Composer, generated by
`build-icons.py` (Vera's approach), so they get glass edges, depth, and iOS's
tinted and clear appearances:

```sh
python3 assets/icons/build-icons.py              # from apps/mobile: every .icon, and previews/
python3 assets/icons/build-icons.py --check /tmp/synq-icons   # also every appearance at 1024 px
```

- `synq.icon`: the primary icon (`ios.icon` in `app.config.ts`).
- `icon-{blue,mint,red,yellow,purple,orange,pink}.icon`: iOS alternate icons,
  which people pick in Settings > App Icon (`src/features/app-icon/app-icon.ts`).
- `synq-dev.icon`: SYNQ Dev's primary icon.
- `previews/`: what Settings shows.

The design stays the one Shawn drew for 2.5.2. `icon-*.png` are its icons (1024 px,
from `origin/2.5.2:src/assets/appIcons`), copied as they were: the script traces
the arrows' shapes from `icon-blue.png` and reads each icon's colors from its own
PNG. Change the design in the PNGs or the script, not in Icon Composer.

**Never rename the `icon-*` documents.** iOS stores the person's choice by the
alternate icon's name, and 2.5.2 named them exactly these. A renamed icon would put
everyone who picked it back on the primary icon after the update.
`plugins/alternate-icons.test.cjs` fails if the list in `app.config.ts`
changes.

`synq-dev.png` is SYNQ Dev's primary icon: the same arrows, dark on amber,
so the dev app stands apart from SYNQ and from every alternate on the home
screen. `render-dev-icon.swift` renders it from `icon-blue.png`:

```sh
swift assets/icons/render-dev-icon.swift   # from apps/mobile
```

`plugins/with-alternate-icons.cjs` copies each alternate into the Xcode project
and lists the names in the build settings.
